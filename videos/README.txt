LeapSphere — Testimonial videos
================================

Drag and drop your testimonial clips into THIS folder and name them:

    1.mp4   →  left frame   (Frontend developer)
    2.mp4   →  center frame (Enterprise developer)  ← the big one
    3.mp4   →  right frame   (Expert)

Tips
----
- MP4 (H.264) plays everywhere. .webm also works if you rename the
  <source> type in index.html.
- Recommended aspect ratio: 16:10, landscape.
- Keep files reasonably small (a few MB) so the page stays fast.
- Until a file is present, the frame shows its placeholder label.
- Clips are muted and start playing when you hover the frame.

Want more/less frames or different labels? Edit the
".testimonials__row" block in index.html.
